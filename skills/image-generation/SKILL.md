# AI Image Generation

Use this skill when the user wants to create, draw, render, illustrate, visualize, or materially edit an image.

## Operation

Use the activated `generate_image` tool rather than trying to simulate image generation with shell commands or prose.

Preserve the user's requested subject, composition, style, constraints, and output intent. When editing an existing image, pass the host-resolved source reference together with the requested change.

Avoid unnecessary clarification when the request is already actionable. If the host cannot bind the advertised image-generation tool, report that capability gap rather than inventing an execution path.

## Retrieval cues

Typical requests include:

- "draw a ..."
- "generate an image of ..."
- "make a picture ..."
- "render ..."
- "illustrate ..."
- "edit this image ..."
- follow-up changes such as "make it watercolor", "remove the background", or "make it more realistic"
